# Task07 – Q7: Diagnose, Redesign and Validate

This Day-4 design challenge selects Q4's long monthly statement builder. Run:

`python3 Task07/streaming_redesign.py`

The program compares three runs of the original `+=` builder and the revised file-streaming builder for the same 200,000 records, validates exact output equality, reports file size and saves raw timings to `Task07/q7_comparison.csv`. Read `design.md` for the diagnosis, measurable objective, pseudocode and trade-offs. Fill the report with measurements from your own Mac.
